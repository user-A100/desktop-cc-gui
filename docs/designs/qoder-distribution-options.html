mossx · Qoder distribution identity

同一个 Qoder 品牌，不该只剩一个模糊的「Qoder」入口

这张稿对比两种客户端形态。两侧都能使用 Global 与 CN；差异在于，用户是否在创建会话时明确选择一个不可混用的运行时身份。

用户选账号域，不选命令 产品层只展示 Global / CN；qodercli 与 qoderclicn 留在高级诊断。
会话身份不可漂移 binary、认证、config home 与 history 在建会话时绑定，之后只读展示。
回执必须可追溯 用户随时能看见本轮实际运行的 distribution，不让 fallback 静默发生。

建议拍板：选择 A
